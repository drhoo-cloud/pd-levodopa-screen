# pipeline/

These are the scripts as they were run for the original screen, carried
forward from v2.1.0 unchanged. Their inline comments are in Korean, the
working language of the laboratory.

Nothing here needs to be read in order to check the paper. The method is
described in English in two places:

- `../run_log.txt` — the eleven steps in order, with the date of each
- `../run_log_laboratory_record.txt` — the laboratory's full working log,
  translated, including why the method was revised and which candidate rules
  were rejected

and the numbers are checked by `../verify_all.py`, which reads only the files
in `../data/`.

The scripts are kept in their original form rather than translated, so that
the code archived under this DOI is byte-identical to the code that produced
the first screen.
